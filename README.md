# TaiCal

macOS 桌面月曆小工具。顯示月曆與台灣國定假日，可直接在小工具上翻月、點選日期。

**這個 repo 只放安裝檔**，程式碼未公開。

## 下載

到 [Releases](../../releases) 下載最新版的 `TaiCal-x.x.zip`。

## 安裝

1. 解壓縮後把 `TaiCal.app` 拖到「應用程式」資料夾
2. 開啟一次 App，依畫面指示授權行事曆（可略過，不影響月曆與假日顯示）
3. 桌面空白處按住 Control 鍵並點一下 → **編輯小工具** → 搜尋 TaiCal
4. 選小型或中型拖到桌面

App 已經過 Apple 公證，可以直接開啟。

## 需求

macOS 14.0 以上。

## 功能

- 月曆格線，標示今天與台灣國定假日
- 農曆（可開關）
- 小工具上直接翻月，中型尺寸可點選日期查看當天事項
- 顯示行事曆事件，可選擇要顯示哪些行事曆來源
- 自訂配色與背景圖，淺色與深色兩套

## 假日資料

來自[政府資料開放平臺的「政府行政機關辦公日曆表」](https://data.gov.tw/dataset/14718)，
由行政院人事行政總處公告。目前涵蓋 2026、2027 年。
